Reescritura de un sistema interno de gestión de tareas para un equipo de 15 personas. Incluye autenticación con JWT, websockets para notificaciones en tiempo real y una API REST completamente documentada.

- Reducción del 40% en tiempo de carga migrando de polling a websockets.
- Suite de tests de integración con cobertura superior al 85%.
- Pipeline de CI/CD con despliegue automático a staging en cada PR.
