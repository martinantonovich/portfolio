Automatización que conecta la plataforma de e-commerce con el sistema contable de la empresa, generando y sincronizando facturas automáticamente ante cada venta.

- Eliminó ~10 horas semanales de carga manual de datos.
- Manejo de reintentos y colas para tolerar caídas del API externo.
- Alertas automáticas ante inconsistencias entre ambos sistemas.
